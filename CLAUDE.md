# Exposure allocation

This is a lean-spec-viewer project: the generated spec page is the developer's
primary interface to this codebase. Before changing anything, read the harness's
patterns document, vendored here as [AGENT.md](AGENT.md).

Core rules: the English is the contract (change it first, then the Lean); never
write status text — build and proof state are derived onto the page; comments are
annotations of declarations (at most one top-level summary per file).
